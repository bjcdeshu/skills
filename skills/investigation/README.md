# 公司调查 · Company Investigations

以公司、人物、投资方、机构、产品或品牌为根节点，核验主体身份、股权穿透、任职与二跳共现伙伴、关联企业、资金与产品运营；适用于任何行业。

Investigate any root entity (company, person, investor, institution, product, or brand) in any industry: identity, look-through ownership, officer roles and co-occurring partners, related entities, funding, and product operations.
